## GameplayChangersSubstate 本土化修复
- 问题：`source/options/GameplayChangersSubstate.hx` 的 `GameplayOption` 用 `LanguageBasic.getPhrase('setting_$name', ...)`（读取 `.lang` 文本文件）解析选项名/值，但 `assets/languages/options/*.json` 里其实已经有对应键（`scrolltype`/`scrollspeed`/`playbackrate` 等），只是从未接线，所以一直回退成英文硬编码。
- 修复：改用 `backend.OptionsLanguage.get(langKey, default)`（读取 `assets/languages/options/*.json`，并入全局 `Language` 表）。`GameplayOption` 内新增 `LANG_KEYS` 映射 + `langKey` 字段；`set_text` 会剥离 `OptionsConfig.SUBMENU_STRING_ARROW` 包裹符再翻译。
- 逻辑比较（曾用 `curOption.name == "Scroll Type"` 等英文硬编码）改为按 `variable` 比较，并把 `getOptionByName` 重命名为 `getOptionByVar`。
- 三个语言文件（en_us/zh_cn/zh_tw）补齐了 `scrolltype`/`scrollspeed`/`playbackrate`/`healthgain`/`healthloss`/`instakill`/`practice`/`botplay`/`playopponent` 名称键，以及 `scrolltype_multiplicative`/`scrolltype_constant` 值键。

## 旧版制谱器(063/073) reloadaudio 修复
- 文件：`source/states/editors/old/OldChartingState063.hx` 与 `OldChartingState073.hx` 的 `loadSong()`。
- 问题1：点 Reload Audio 后，`loadSong()` 重新 `playMusic` 加载伴奏但立即 pause 在章节起点，人声只 `loadEmbedded` 却从未 `play()`，也没同步 `time`/音量 → 人声失声、感觉"没重载"。
  - 修复：`loadSong()` 末尾对 vocals（073 含 opponentVocals）做 `play(); pause(); time = Conductor.songPosition;` 并恢复音量（对齐新版 `ChartingState.loadMusic`）。
- 问题2：`Paths.inst/voices` 走 `returnSound()` 静态缓存 `currentTrackedSounds`，已加载过的音频不会重新读盘，改了磁盘上的 ogg 再点重载也不生效。
  - 修复：`loadSong()` 开头先遍历 `Paths.currentTrackedSounds`，清掉 `/songs/<currentSongName>/` 下的缓存（close + `OpenFlAssets.cache.clear` + remove + `localTrackedAssets.remove`），对齐新版 `loadMusic(true)` 的 killAudio 逻辑。
- 两文件均 `import openfl.utils.Assets as OpenFlAssets`，可直接用 `OpenFlAssets.cache.clear`。
- 验证：read_lints 两个文件均无错误。默认"重载回到章节起点、保持 pause"语义保留。
